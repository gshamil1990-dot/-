# Руководство по запуску сайта MAGDANA на собственном домене и оффлайн

В проекте настроены **три готовых сценария работы** из одной кодовой базы:
1. **Автономный оффлайн-файл** (`magdana-offline.html`) — работает без интернета и без сервера.
2. **Статический сайт с PWA на вашем домене** (Beget, Timeweb, REG.RU, Cloudflare Pages, Netlify) — самый простой и экономичный запуск.
3. **Полный Node.js-сервер на VPS** — если нужна встроенная AI-генерация фото моделей в кабинете мастера.

---

## 1. Автономный оффлайн-файл (открывается без интернета)

После сборки готовый файл находится в папках `public/` и `dist/`:
- `public/magdana-offline.html` (копируется в `dist/magdana-offline.html` при сборке)

**Как использовать:**
- Скопируйте `magdana-offline.html` на компьютер, флешку или телефон и откройте двойным кликом в любом браузере (Chrome, Safari, Edge, Firefox).
- Внутри уже встроены дизайн, весь каталог из 83 услуг, портфолио с фильтром по категориям (`Окрашивание`, `Стрижки`, `Спа-уход`, `Укладки`), просмотрщик фото и форма записи с прямыми ссылками в Telegram, WhatsApp, MAX и на звонок.
- Также клиенты и вы сами можете скачать актуальный оффлайн-файл прямо с работающего сайта по ссылке **«Оффлайн-версия (HTML)»** в нижней части страницы.

**Как пересобрать оффлайн-файл после правок цен или услуг:**
```bash
npm run build:offline
```

## 2. Запуск сайта на собственном домене (Статический хостинг — Рекомендуемый старт)

На статическом хостинге полностью работают: главная страница, чистые URL (`/coloring`, `/haircuts`, `/care`, `/styling`, `/portfolio`), PWA (установка на экран телефона и работа оффлайн после первого визита), онлайн-запись, облачное портфолио из Firebase и **кабинет мастера** (вход через Google-аккаунт владельца + загрузка своих фото работ).

### Шаг 1. Купите домен
Зарегистрируйте домен (например, `magdana-studio.ru`) у любого регистратора: **REG.RU**, **Timeweb**, **Beget** или **Cloudflare**.

### Шаг 2. Обновите домен в SEO-файлах
Перед сборкой замените `https://example.ru` на ваш реальный домен в двух файлах:
- `public/robots.txt`
- `public/sitemap.xml`

### Шаг 3. Соберите сайт
```bash
npm install
npm run build:offline
```
В папке `dist/` появятся все готовые файлы сайта, включая `.htaccess` (для Beget / Timeweb / REG.RU), `_redirects` (для Cloudflare Pages / Netlify), PWA-манифест, Service Worker и `magdana-offline.html`.

### Шаг 4. Загрузите папку `dist/` на хостинг
- **Вариант A — Cloudflare Pages / Netlify (бесплатно, с авто-HTTPS):**
  1. Подключите репозиторий или перетащите папку `dist/` в панель деплоя.
  2. В разделе **Custom Domains** привяжите ваш купленный домен и добавьте указанные DNS-записи у регистратора.
  3. SSL-сертификат (HTTPS) выпустится автоматически за несколько минут.
- **Вариант B — Beget / Timeweb / REG.RU (обычный веб-хостинг):**
  1. Привяжите домен в панели хостинга и включите бесплатный SSL-сертификат **Let's Encrypt** (обязательно для работы PWA и Firebase).
  2. Загрузите всё содержимое папки `dist/` (включая скрытый файл `.htaccess`) в корневую директорию сайта (обычно `public_html/`).

### Шаг 5. Разрешите ваш домен в Firebase (для входа мастера через Google)
Чтобы кнопка входа через Google в кабинете мастера работала на новом домене:
1. Откройте [Firebase Console](https://console.firebase.google.com/) и выберите ваш проект.
2. Перейдите в **Authentication → Settings → Authorized domains**.
3. Нажмите **Add domain** и добавьте ваш домен (например, `magdana-studio.ru` и `www.magdana-studio.ru`).

## 3. Запуск на VPS / Node.js-хостинге (если нужна AI-генерация фото)

Если вам нужна встроенная генерация фото моделей через Gemini API и вход по PIN-коду:
1. Арендуйте VPS с Node.js 20+ (Timeweb Cloud, Selectel, REG.RU VPS и т. п.) и привяжите домен через Nginx с HTTPS (Certbot).
2. Создайте файл `.env` на сервере по образцу `.env.example`:
   ```env
   NODE_ENV=production
   PORT=3000
   GEMINI_API_KEY=ваш_ключ_gemini
   MASTER_STUDIO_PIN=ваш_секретный_pin
   ```
3. Соберите и запустите сервер (рекомендуется под управлением `pm2`):
   ```bash
   npm install
   npm run build:offline
   npx tsx server.ts
   ```
4. В Nginx настройте `proxy_pass http://127.0.0.1:3000` для вашего домена.
